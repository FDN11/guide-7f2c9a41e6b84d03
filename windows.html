Практическая инструкция · Windows / PowerShell

Codex в терминале.
С нуля до первой задачи.

Установка, работа с файлами, поиск в интернете и дополнительные агенты — шаг за шагом.

Команды запуска и установки — в PowerShell. Задачи и команды со знаком / — в открытый Codex. Кнопка «Копировать» поможет вставить текст без ошибок.
01

Открой PowerShell

Нажми Win, введи «PowerShell» и открой приложение. В Windows Terminal выбери вкладку PowerShell. Команды вставляй по одной, каждый раз нажимая Enter и дожидаясь завершения.

02

Установи Node.js и Codex

Если установщик install.ps1 завершился ошибкой OSArchitecture, используй этот способ. Сначала установи Node.js LTS вместе с npm:

winget install --id OpenJS.NodeJS.LTS --exact --source winget

Если winget не найден, скачай LTS-установщик с официального сайта Node.js и установи с обычными настройками. После установки полностью закрой терминал и открой PowerShell заново. Проверь:

node --version
npm.cmd --version

Затем установи Codex:

npm.cmd install -g @openai/codex@latest

Суффикс .cmd позволяет запускать команды без изменения политики выполнения PowerShell-скриптов.

03

Проверь установку

Полностью закрой PowerShell или Windows Terminal и открой заново. Команда должна показать номер версии. Если команда codex.cmd не найдена, проверь указания установщика по добавлению программы в PATH. Для установки через npm проверь, что папка из вывода npm.cmd config get prefix добавлена в пользовательский PATH.

codex.cmd --version
04

Войди в ChatGPT

Откроется браузер. Войди в свой аккаунт, заверши авторизацию и вернись в PowerShell. API-ключ для этого способа не нужен. Доступ и лимиты зависят от аккаунта и тарифа.

codex.cmd login
05

Проверь вход

Эта команда показывает состояние авторизации.

codex.cmd login status
06

Выбери рабочую папку

Для первых задач создай отдельную папку в своём профиле Windows. Для существующего проекта скопируй путь из адресной строки Проводника и выполни Set-Location "C:\путь\к\проекту". Кавычки нужны, если в пути есть пробелы.

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\Codex-work"
Set-Location "$env:USERPROFILE\Codex-work"
07

Запусти с интернет-поиском

Откроется интерфейс общения. Дальше пиши задачи обычными словами. Флаг --search включает актуальный веб-поиск; управление кнопками и формами сайтов требует отдельного браузерного инструмента.

codex.cmd --search
08

Дай первую задачу

Этот текст вставляй уже в поле сообщения Codex, а не в командную строку оболочки.

Отвечай по-русски. Изучи текущую папку и коротко объясни, какие здесь файлы и чем ты можешь помочь. Пока ничего не меняй.
09

Настрой разрешения

Введи команду внутри Codex. Для начала выбери режим с редактированием и выполнением команд в рабочей папке и запросом доступа за её пределами.

/permissions
10

Задай стиль работы

Вставь как сообщение в Codex. Инструкция задаёт стиль работы, но не отменяет ограничения доступа.

Самостоятельно выполняй согласованную задачу до готового результата: изучай файлы, вноси изменения, запускай необходимые команды и проверяй результат. Не спрашивай подтверждение каждого обычного шага. Если не хватает доступа — объясни, какой нужен. Учитывай, что работаешь в Windows через PowerShell.
11

Подключай агентов

В актуальных версиях субагенты включены по умолчанию, скачивать их отдельно не нужно. Каждый агент расходует дополнительные лимиты.

Используй субагентов для этой задачи. Одному поручи изучение проекта, второму — проверку документации. Собери их выводы, затем выполни необходимые изменения и проверь результат.
12

Посмотри работу агентов

Команда вводится внутри Codex.

/subagents
13

Сохрани правило для проекта

Попроси Codex записать постоянную инструкцию в AGENTS.md.

Добавь в AGENTS.md этого проекта правило: при сложных задачах делегировать независимые части субагентам, когда это помогает скорости или качеству. Также добавь правило: рабочая среда — Windows и PowerShell; используй совместимые команды. Существующие инструкции сохрани.
14

Вернись к предыдущей работе

Чтобы выйти из Codex в PowerShell, введи /quit. Затем из папки проекта запусти команду ниже: появится выбор сохранённых чатов.

codex.cmd resume
15

Продолжи последний чат

Выполни в PowerShell из папки проекта: продолжится последний чат с актуальным веб-поиском.

codex.cmd --search resume --last
16

Обнови Codex

Если установил Codex через npm по шагу 02, обнови его командой ниже. После обновления проверь codex.cmd --version.

npm.cmd install -g @openai/codex@latest

Несколько вкладок — необязательно

В Windows Terminal нажми «+», чтобы открыть ещё одну вкладку PowerShell. В каждой вкладке перейди в нужную папку и запусти codex.cmd --search.

Если нужен именно tmux, используй его внутри WSL. Для обычной работы достаточно вкладок Windows Terminal. Закрытие терминала завершает запущенный в нём процесс. Сон и выключение компьютера останавливают локальную работу.

Версия Windows и первый запуск

Предпочтительно использовать Windows 11. На обновлённой Windows 10 поддержка предоставляется с ограничениями. Если Codex предложит настроить защитную среду Windows (sandbox), следуй подсказкам. Некоторым вариантам настройки требуется подтверждение администратора.

Что подключается отдельно

Для GitHub, браузера и других внешних сервисов могут потребоваться плагины, MCP-инструменты и авторизация. История и настройки Claude Code автоматически не переносятся.
