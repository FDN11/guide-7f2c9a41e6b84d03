Практическая инструкция · macOS

Codex в терминале.
С нуля до первой задачи.

Установка, работа с файлами, поиск в интернете и дополнительные агенты — шаг за шагом.

Команды запуска и установки — в Терминал. Задачи и команды со знаком / — в открытый Codex. Кнопка «Копировать» поможет вставить текст без ошибок.
01

Открой Терминал

Нажми ⌘ + пробел, введи «Терминал» и нажми Enter. Команды вставляй по одной, каждый раз нажимая Enter и дожидаясь завершения.

02

Установи Codex

Официальный установщик OpenAI для macOS. Отдельно устанавливать Node.js или Homebrew для этого способа не нужно.

curl -fsSL https://chatgpt.com/codex/install.sh | sh
03

Проверь установку

Закрой окно терминала и открой новое. Команда должна показать номер версии. Если видишь command not found, выполни указания установщика по добавлению программы в PATH.

codex --version
04

Войди в ChatGPT

Откроется браузер. Войди в свой аккаунт, заверши авторизацию и вернись в терминал. API-ключ для этого способа не нужен. Доступ и лимиты зависят от аккаунта и тарифа.

codex login
05

Проверь вход

Эта команда показывает состояние авторизации.

codex login status
06

Выбери рабочую папку

Для первых задач создай отдельную папку. Для существующего проекта набери cd с пробелом, перетащи папку из Finder в терминал и нажми Enter.

mkdir -p ~/Documents/Codex-work
cd ~/Documents/Codex-work
07

Запусти с интернет-поиском

Откроется интерфейс общения. Дальше пиши задачи обычными словами. Флаг --search включает актуальный веб-поиск; управление кнопками и формами сайтов требует отдельного браузерного инструмента.

codex --search
08

Дай первую задачу

Этот текст вставляй уже в поле сообщения Codex, а не в командную строку оболочки.

Отвечай по-русски. Изучи текущую папку и коротко объясни, какие здесь файлы и чем ты можешь помочь. Пока ничего не меняй.
09

Настрой разрешения

Введи команду внутри Codex. Для начала выбери режим с редактированием и выполнением команд в рабочей папке и запросом доступа за её пределами.

/permissions
10

Задай стиль работы

Вставь как сообщение в Codex. Инструкция задаёт стиль работы, но не отменяет ограничения доступа.

Самостоятельно выполняй согласованную задачу до готового результата: изучай файлы, вноси изменения, запускай необходимые команды и проверяй результат. Не спрашивай подтверждение каждого обычного шага. Если не хватает доступа — объясни, какой нужен.
11

Подключай агентов

В актуальных версиях субагенты включены по умолчанию, скачивать их отдельно не нужно. Каждый агент расходует дополнительные лимиты.

Используй субагентов для этой задачи. Одному поручить изучение проекта, второму — проверку документации. Собери их выводы, затем выполни необходимые изменения и проверь результат.
12

Посмотри работу агентов

Команда вводится внутри Codex.

/subagents
13

Сохрани правило для проекта

Попроси Codex записать постоянную инструкцию в AGENTS.md.

Добавь в AGENTS.md этого проекта правило: при сложных задачах делегировать независимые части субагентам, когда это помогает скорости или качеству. Существующие инструкции сохрани.
14

Вернись к предыдущей работе

Запусти в обычном терминале: появится выбор сохранённых чатов.

codex resume
15

Продолжи последний чат

Запуск последнего чата с актуальным веб-поиском.

codex --search resume --last
16

Обнови Codex

При установке официальным скриптом обновление выполняется той же командой.

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Несколько окон через tmux — необязательно

Если tmux уже установлен, создай сессию командой tmux new -s codex, затем запусти в ней codex --search. Codex работает и без tmux — в обычных вкладках терминала.

  • Новое окно: Ctrl + B, отпустить, затем C.
  • Следующее окно: Ctrl + B, затем N.
  • Переименовать окно: Ctrl + B, затем запятая.
  • Отключиться от сессии: Ctrl + B, затем D.
  • Вернуться: tmux attach -t codex.

tmux не обеспечивает работу во время сна или выключения Mac.
